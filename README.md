# HooBank — Modern Banking Landing Page

A responsive marketing site for a fictional fintech product, built as a React
single-page layout with Tailwind CSS.

[Live demo](https://bank-modern-proj.netlify.app)

## Sections

Hero · Stats bar · Business features · Billing · Card deal · Testimonials ·
Client logos · Call to action · Footer

Each section is its own component under `src/components`, with copy and data
kept separately in `src/constants`.

## Stack

React 18 · Vite · Tailwind CSS

## Running locally

```bash
npm install
npm run dev
```
